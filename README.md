## Como executar localmente

Este projeto utiliza HTML, CSS e JavaScript. Se o repositório possuir um arquivo `index.html` na pasta principal, é possível visualizar o site diretamente no navegador.

1. Clone o repositório:

   ```bash
   git clone https://github.com/Deutzan/portfolio-profissional.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd portfolio-profissional
   ```

3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências com `npm` para um site estático simples. Caso o projeto utilize alguma ferramenta adicional, as instruções deverão ser ajustadas.
